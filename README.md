# Screw Puzzle

A free single-file HTML5 puzzle game: unscrew layered colorful plates, sort
screws in an 8-slot tray, match 3 of a color to clear it. 60 levels, star
ratings, progress saved locally.

- Play: https://shuangyueliao.github.io/screw-puzzle/
- Zero external assets — canvas graphics, WebAudio sound, no tracking.
- Platform SDKs (CrazyGames / GameDistribution) load only on their domains.
